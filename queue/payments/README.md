# Payment Receipts Queue

This directory contains payment receipts generated by the Stripe webhook at `https://citedhq.ai/api/stripe/webhook`.

## File Format

Each payment receipt is stored as a JSON file with the naming pattern:
```
payment_{stripe_event_id}_{timestamp}.json
```

## Receipt Structure

```json
{
  "event_id": "evt_1234567890",
  "event_type": "checkout.session.completed",
  "timestamp": "2026-09-18T08:23:00.000Z",
  "status": "paid",
  "customer_email": "user@example.com",
  "amount": 150000,
  "currency": "usd",
  "payment_metadata": {
    "sku": "FOCUS",
    "tier": "FOCUS",
    "company": "Cited",
    "product_id": "prod_VH9MGzpZxPHuxw",
    "price_id": "price_1UGb48IIPbN1sDgZai2qjLBW",
    "payment_link": "https://buy.stripe.com/7sY4gA9DQcvb8ZDeda0Ba02"
  }
}
```

## Conductor Integration

For Conductor queue processing:

1. **Monitor this directory** for new payment receipts
2. **Verify receipt status** is `"paid"`  
3. **Extract customer email and SKU** from receipt
4. **Create Conductor ticket** with state transition: `paid` → `intake_open`
5. **Archive processed receipt** to `queue/payments/processed/`

## SKU Mapping

| SKU | Product | Amount | Mode |
|-----|---------|--------|------|
| `PILOT-499` | Bot AEO Pilot — $499 | $499 | one_time |
| `PILOT-750` | Bot AEO Pilot — $750 | $750 | one_time |
| `FOCUS` | Bot AEO Focus | $1,500/mo | recurring |
| `STD` | Bot AEO Standard | $2,500/mo | recurring |
| `FULL` | Bot AEO Full | $3,500/mo | recurring |

## Implementation Notes

- **Day-0**: File-based receipts for simple processing
- **Production**: Move to Cloudflare KV/R2 or external webhook for durability
- **Never log** the `STRIPE_WEBHOOK_SECRET` value
- **Verify signature** before processing any webhook data
